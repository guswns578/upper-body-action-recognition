# MMA-52 상반신 행동 인식 기준 모델 v1 — 2026-10-27

## 설정
- 입력: RTMW-l 상반신 13점(코·눈·귀·어깨·팔꿈치·손목·골반). 원점은 양어깨 중점, 크기는 과거 2초 어깨 너비 중앙값(인과적). 좌표 26 + 속도 26 + 표준화 점수 13 = 65차원/프레임.
- 라벨: MMA-52 52종 중 다리·발 12종 제외 40종, 프레임별 다중 라벨(구간 끝 포함).
- 모델: 과거만 보는 TCN(팽창 1~32, 수용 범위 127프레임 ≈ 4.2초, 41만 파라미터), GRU(2층, 21만 파라미터).
- 학습: 256프레임 무작위 자르기, 증강(좌우 반전, 회전 ±10°, 크기 ±10%, 30% 골반 가림, 관절 3% 결측, 잡음), BCE + 클래스별 양성 가중치(상한 20), AdamW, 40 epoch.
- 점검(E0): 미래 프레임을 바꿔도 과거 출력 변화 0(두 모델). 한 배치 과적합 성공.
- 코드: `build_cache.py`, `group_subjects.py`, `train.py`. 결과: `runs/*/results.json`.

## 개발셋 문제와 해결
- 처음에는 train 영상의 무작위 10%를 개발셋으로 썼다 → **dev mAP 0.483 vs 공식 val 0.147**. 같은 사람이 train·dev에 섞여 사람의 자세 습관을 외운 결과였다(팔짱 dev 0.93 vs val 0.05).
- 공식 사람 ID가 없어서 옷 색 히스토그램으로 영상을 사람 단위로 묶었다(`group_subjects.py`). val(공식 37명)에서 37군집이 시각적으로 깨끗함을 확인했다. train은 사람을 둘로 쪼개지 않도록 실제(140명)보다 적은 100군집으로 묶었다.
- 군집 단위로 떼어 낸 개발셋은 dev 0.09~0.12, val 0.12~0.16으로 **더 이상 부풀려지지 않는다**. 이후 모든 모델 선택은 이 개발셋으로 한다.

## 해석
1. **손이 몸·얼굴에 닿는 행동은 좌표만으로 배운다.** 우연 수준의 6~13배.
2. **머리 동작은 사실상 못 배웠다.** 끄덕임·가로젓기·기울이기가 우연 수준이다. 머리 점이 5개(코·눈·귀)뿐이고 MMA-52에서 머리가 작아(어깨 너비 155px) 작은 움직임이 잡음에 묻히는 것으로 보인다. RTMW 얼굴 68점(이미 추출됨)이 다음 후보다.
3. **TCN이 GRU보다 일관되게 낫다**(0.14 vs 0.10). 10초 안팎 영상에서는 GRU의 긴 기억 장점이 드러나지 않았다.
4. **팔짱(val 16구간)은 수치를 믿기 어렵다.** 우연 수준보다는 높지만 절대값이 낮다.
5. 시작 지연 지표는 AP가 우연 수준인 클래스에서 의미가 없다(임계값이 낮아 항상 켜짐). AP가 충분한 클래스부터 해석한다: 손짓 0.5초, 팔짱 0.9초, 손끝 맞대기 1.3초(TCN s0).

## 한계
- 사람 군집은 옷 색 기반 추정이다. train 군집은 여러 사람을 합친 경우가 있다(보수적인 방향).
- "상반신 라벨 없음" 프레임이 실제 행동 없음인지 보장되지 않아 오검출률은 참고용이다.
- 하이퍼파라미터는 거의 조정하지 않았다(강한 정규화 1회 시도: val 0.139, 개선 없음).

## E2a: 얼굴 17점 추가 (2026-10-27)
- 입력에 얼굴 17점(턱·눈썹·코·눈꼬리·입)을 추가했다. 얼굴 중심 기준, 양 눈 바깥 꼬리 거리(과거 2초 중앙값)로 정규화한 국소 좌표 + 속도 + 얼굴 중심 위치(어깨 기준) + 점수 → 입력 154차원(`build_face_cache.py`, `train.py --face`). 좌우 반전 시 얼굴 점도 좌우 교환.
- 전체 val mAP: 0.142 ± 0.015 → **0.146 ± 0.003** (TCN 3시드). 전체로는 차이가 없다.
- 머리 동작은 뚜렷하게 올랐다(3시드 평균 val AP, 괄호는 우연 수준):

- 해석: 얼굴 크기로 정규화한 얼굴 점이 머리 움직임을 드러낸다는 가설을 지지한다. 다만 끄덕임·가로젓기는 아직 절대값이 낮다. 손 흔들기 하락은 입력이 커지면서 손·팔 정보의 비중이 줄었을 가능성이 있다(미확인). 몸·얼굴을 따로 처리한 뒤 합치는 구조가 다음 후보다.

## E3: 머리 동작 배제 후 팔·손·몸 동작 (2026-10-28)
- 결정: 머리 동작 6종(숙이기, 들기, 기울이기, 돌리기, 끄덕임, 가로젓기)은 일단 출력하지 않는다. 끄덕임은 앞으로도 출력하지 않는다.
- 평가: 머리를 뺀 24종 val mAP. 단일 모델은 3시드 평균 ± 표준편차, 앙상블은 3시드 확률 평균이다. 앙상블 임계값은 개발셋에서 다시 고른다(`practical_eval.py run1 run2 run3 --out ens_...`).
- 추가 옵션:
  - `--hands`: 손 21점의 평균 위치와 평균 점수를 관절 2개로 덧붙인다(15점, 75차원). 손이 어디 있는지만 쓰고 손가락 모양은 쓰지 않는다.
  - `--no-head`: 머리 6종을 학습 손실에서도 뺀다.

| 설정 | 단일 모델 mAP24 | 앙상블 mAP24 | 앙상블 평균 F1 | 앙상블 헛검출 합계/분 |
|---|---|---|---|---|
| 몸 13점(기존) | 0.154 ± 0.018 | 0.174 | 0.127 | 74.0 |
| 몸 13점 + 얼굴(두 갈래) | 0.141 ± 0.013 | – | – | – |
| 몸 13점, 머리 손실 제외 | 0.137 ± 0.017 | 0.154 | 0.127 | 72.7 |
| 몸 13점 + 손 중심, 머리 손실 제외 | 0.161 ± 0.020 | 0.177 | 0.134 | 57.1 |
| **몸 13점 + 손 중심** | **0.186 ± 0.008** | **0.194** | **0.150** | 69.7 |

해석:
1. **손 중심점이 가장 큰 개선이다.** 단일 모델 기준 +0.03이고, 시드 편차도 0.018에서 0.008로 줄었다. 손목만 보던 때보다 손이 몸이나 얼굴의 어디에 닿는지가 더 정확해진다.
2. **머리 라벨은 출력하지 않더라도 학습에는 남기는 게 낫다.** 학습 손실에서 빼면 두 설정 모두 약 0.02 내려갔다. 머리 라벨이 "이 움직임은 팔이 아니라 머리다"를 알려 주는 보조 과제 역할을 하는 것으로 보인다(가설).
3. **얼굴 점은 머리를 뺀 평가에서는 오히려 손해다.** 다음 실험의 기준은 `--hands`(얼굴 없음)로 한다.
4. **큰 팔 동작은 여전히 약하다.** 손 흔들기, 팔 뻗기, 손 펼치기, 설명 손짓, 팔짱, 몸 흔들기, 팔 거두기 7종의 평균 AP는 0.135다. MMA-52는 미세 행동(micro-action) 데이터셋이라 같은 이름이라도 동작이 작다. 따라서 큰 동작 중심의 목표와 데이터가 어긋난다.
5. 구간이 10~17개뿐인 클래스(등 긁기, 눈 비비기, 팔짱 등)는 수치 변동이 크다.
