# MMA-52 RTMW-l 좌표 추출 — 2026-10-26

포즈 추출기 비교(`src/pose_compare`)에서 RTMW-l을 주 추출기로 정했고, MMA-52 train·val 영상 전체에서 133점 좌표를 뽑는다.

## 데이터
- MMA-52 (kunli-cs/MMA-52, revision 4da5a2f0), 비상업 학술 연구 전용 동의서 서명(2026-10-26 승인).
  **데이터와 파생 라벨 파일은 제3자에게 넘기지 않는다. 이 데이터로 학습한 모델은 상업 시스템에 쓰지 않는다.**
- ZIP 위치 `data/MMA-52/*.zip`(크기·CRC 검증), 풀어 둔 영상 `data/MMA-52/videos/{train,val}` (4,534 / 1,475개).
- test는 라벨이 무작위라 추출·평가에서 제외한다.
- 영상: 900×1080, 30fps(일부 29), 흰 벽·의자에 1인 전신 착석. 어깨 너비 중앙값 약 155px로 우리 목표 구도보다 2.5~4배 작다.

## 추출 설정 (`extract_mma52_rtmw.py`, gpu_env)
| 항목 | 값 |
|---|---|
| 사람 박스 | YOLOX tiny 416, 점수 0.3 이상, 첫 프레임 최대 박스 → 이후 IoU 추적 |
| 포즈 | RTMW-dw-x-l 384×288 (`work/pose_models/rtmw_384.onnx`), rtmlib 0.0.14와 같은 전처리·SimCC 디코딩 |
| 실행 | onnxruntime-gpu 1.31 CUDA, **FP32(use_tf32=0)**, 배치 64, 4개 프로세스 분할 |
| 저장 | `data/MMA-52/pose_rtmw/{split}/{video}.npz`: `xy[T,133,2]` float32 원본 픽셀, `score[T,133]` float16, `box[T,4]`, `has_person[T]`, `fps` |

## 검증
- 같은 사람 박스를 주면 몸 17점이 pose_env CPU(rtmlib) 결과와 **0.0001px 이내로 같다**.
- GPU 검출기 박스가 CPU와 최대 0.0004px 달라, 일부 좌표가 SimCC 한 칸(이 영상 기준 약 1.6px) 뒤바뀐다(몸 0.08% 이하). 손 좌표도 같은 크기의 한 칸 차이가 드물게 있다. 학습에 영향 없는 수준으로 보고 받아들였다.
- TF32를 켜면 2배 빠르지만 같은 한 칸 차이가 더 생겨서 끔.
- 정규화를 float32로 하면 0.07% 좌표가 한 칸 달라져서, rtmlib과 같이 float64로 정규화한다.
- 시험 추출 30개 영상: 오류 0, has_person 100%. 겹쳐 그린 결과 `data/MMA-52/samples/rtmw_trial.jpg`.

## 전체 추출 결과 (2026-10-26 완료)
- val 1,475 / train 4,534개 영상 전부 저장, 오류 0. 총 1,862,833프레임(val 468,524, train 1,394,309).
- 모든 영상에서 사람 검출 99% 이상, NaN/무한대 좌표 0.
- 실행 속도: 2개 프로세스 약 80프레임/초. 4개 프로세스는 GPU 메모리 경합으로 오히려 느려져서(약 48fps) 2개로 했다.
- **val 14개 영상은 CSV의 `total_frames`보다 실제 프레임이 적다**(예: val0646 229 vs 390). OpenCV와 PyAV 두 디코더가 같은 수를 내고, 모든 주석 구간의 끝 프레임이 실제 길이 안에 있다. 라벨 손실은 없으며, 학습 시 영상 길이는 npz의 프레임 수를 기준으로 쓴다.
  목록: val0053, 0595, 0646, 0650, 0747, 0787, 0847, 0890, 1168, 1206, 1246, 1343, 1347, 1357.

## 사용 원칙(라벨 v0·과제 합의)
- 학습 입력은 **상반신 13점**(코·눈·귀·어깨·팔꿈치·손목·골반) + 필요 시 손 42점. 다리 4점(무릎·발목)과 발 6점은 쓰지 않는다.
- 다리 관련 라벨(shaking legs, crossing legs 등)은 학습 목표에서 뺀다. 그 영상의 상반신 라벨은 쓴다.
- 점수는 확률이 아니다. 관찰 불가 판정 임계값은 정답 세트로 정한다.
