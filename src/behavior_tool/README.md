# 범용 행동 도구 v1 — 구현 및 검증 기록 (2026-09-16)

## 실행
`python analyze.py <영상>`으로 실행합니다. 인자 없이 실행하면 영상 선택 창이 열립니다.
기본: YOLOX tiny → ByteTrack → RTMPose M 17점 → 기하 품질 검사 → 팔짱 후보 규칙 → JSON/한글 영상.
`--hands`: RTMW 133점 + MediaPipe 손 추출. `--action-model none`: 좌표만 기록.
`--action-model mmn --hands`: MMN 실험 어댑터. 아직 검증된 인식기로 취급하지 않습니다.
결과는 src/video_tool_runs 아래 새 폴더에 저장합니다. 원본은 수정하지 않습니다.

## 이번 변경
- 전경 한 사람 선택을 없애고 검출된 여러 사람을 추적합니다. 작은 사람은 좌표 분석을 보류합니다.
- SimCC 점수는 저장만 합니다. 좌표 채택에 점수 임계값을 사용하지 않습니다.
- 유한 좌표/화면 범위/어깨폭, 투영 뼈 길이, 박스 경계, 이전 좌표 대비 점프와 뼈 길이 변화를 검사합니다.
- 빠른 일관된 움직임은 점프만으로 제거하지 않습니다. 현재 수치 임계값은 검증 전 휴리스틱입니다.
- 2D 관절 각도는 실제 3D 해부학적 가동범위와 다르므로 품질의 강제 탈락 기준으로 넣지 않았습니다.
- 기하 검사 통과는 가시성 증명이 아닙니다. visibility는 unknown입니다. 그럴듯하게 환각된 가린 손목은 아직 걸러지지 않을 수 있습니다.
- 파일을 미리 훑어 컷을 찾고 ±0.2초 행동 분석을 보류합니다. 컷에서 추적·동작 이력을 초기화합니다. 오프라인 방식이며 실시간 이전 프레임 판정에는 지연 버퍼가 필요합니다.
- ByteTrack ID는 장면 내부 임시 ID입니다. 가림/교차 시 ID 유지 보장은 없습니다.
- 규칙 인식기는 좌표→update→finish 인터페이스로 분리했습니다. 팔짱 후보가 0.3초 유지되면 구간으로 출력합니다. 짧은 결측 0.15초는 보존하되 마지막 실제 관찰 시점에서 구간을 끝냅니다.

## 현재 지원 범위
실제 연결된 행동 인식기는 **팔짱 후보** 하나입니다. 행동이 없다는 판정과 지원 행동 미검출은 다릅니다.
삿대질은 제안서의 예시이며 반드시 두 행동만 해야 한다는 요구로 해석하지 않습니다.
팔 뻗기 이벤트/검지 가리키기/대상 인물 추정은 아직 미구현입니다. 팔 좌표만으로 이를 확정하지 않습니다.
MMN은 Motion-guided Modulation Network이며 공식 구현은 https://github.com/momiji-bit/MMN 입니다.

## 출력 및 통합 계약
- observations.jsonl: 프레임별 people, track_id, scene_id, speaker_id, status, visibility, quality_flags, track_id_kind, 몸 좌표와 원시 점수.
- action_updates.jsonl: 현재는 종료된 팔짱 후보 구간만 저장. kind=segment, start/end는 원본 영상의 초 단위 관찰 시각. 처리 종료 사유 포함. 실시간 시작 알림은 아직 없음.
- 이벤트 확장 계약: kind=event, at, label, target_pid(null 허용). 구현된 이벤트가 없으므로 빈 이벤트를 꾸며내지 않습니다.
- review_ko.mp4: 사람용 한글 점검 영상. 무음이며 고정 FPS. JSON의 디코드 시각이 시간 정보의 기준입니다.
- --speaker-map mapping.json: {"S001-P0001":"speaker_A"} 형식의 외부 매핑. 미지정은 null. 좌석↔트랙 확인은 외부 정렬 단계 책임이며 컷마다 재매핑합니다.
- fusion_contract.json: 발화 단위 고정 길이 벡터 인터페이스 예약. 집계기는 아직 미구현. 자막 문자열을 다시 파싱하지 않습니다.

## 연산 계획
현재 환경은 CPU ONNX Runtime입니다. GPU 설치 여부를 추정하지 않습니다.
기본은 원래 FPS를 유지합니다. 5fps 전체 스캔은 빠른 움직임을 놓칠 수 있어 기본 경로에 넣지 않았습니다.
대량 처리 전 summary.json의 processing_seconds/영상 길이로 비용을 측정하고, CUDA 공급자 설치/검증 후 같은 회귀 세트를 재실행합니다.
현재 전체 도구의 실시간 속도나 300시간 처리 시간을 보장하지 않습니다.

## 검증 상태
test_contracts.py: 점수 불변성, 비정상 좌표, 빠른 일관 움직임 보존, 컷, 짧은 결측/구간 종료의 5개 테스트 통과.
다인물 샘플 72프레임 실행 완료: 2개 ID, JSON과 한글 영상 생성.
방송 영상은 별도 실행 결과 summary.json 참고. 이것은 행동 인식 정확도 검증이 아닙니다.
요청한 실제 영상 회귀 4종(48초 손목 상승, 가린 손 관찰 불가, 컷 경계, ID 정답 일치)은 아직 합격 판정하지 않았습니다.
특히 손목 상승 인식 부품과 가림 검증기가 없으므로 현재 버전을 그 회귀에 합격했다고 주장하지 않습니다.
다음 단계는 해당 부품 구현과 독립 정답 구간 확보 후 실패/통과를 고정하는 것입니다.
