# 포즈 추출기 비교 v1 — 2026-10-26

목적: 상반신 행동 인식의 입력이 될 2D 포즈 추출기를 고른다. 제안서에 명시된 OpenPose와 현재 시제품의 RTMPose 계열, MediaPipe를 같은 조건에서 비교한다.
**정답 좌표가 없는 비교**다. 정확도가 아니라 결측·흔들림·모델 간 합의·좌우 뒤바뀜·속도를 본다.

## 조건

| 항목 | 내용 |
|---|---|
| 영상 | Pexels 착석·정면 6개 + AI-Hub 강조 제스처 44 (70~92초). 7구간, 2,377프레임 |
| 사람 박스 | YOLOX tiny로 한 번 계산해 모든 모델이 공유(`prepare_clips.py`) |
| 공통 관절 | 상반신 13점(코·눈·귀·어깨·팔꿈치·손목·골반), 해부학적 좌우 |
| OpenPose | COCO-18 body, PyTorch 변환 가중치(lllyasviel/Annotators), 1 스케일·망 높이 368(공식 기본). 확장 크롭 입력 |
| RTMPose-m | 17점, 256×192, onnxruntime CPU |
| RTMW-l | 133점(손 42점 포함), 384×288, onnxruntime CPU |
| MediaPipe | Pose Landmarker heavy, IMAGE(프레임 독립)와 VIDEO(공식 스트리밍, 추적·평활) 두 모드 |

코드: `prepare_clips.py`, `extract_pose_env.py`, `extract_openpose.py`, `analyze.py`. 원자료 `raw/`, 지표 `metrics.json`, 시각 비교 `figs/*.jpg`.

## 관찰

1. **OpenPose는 가까운 구도에서 손목을 놓친다.** 손이 화면에 크게 잡힌 6100890에서 손목 결측이 77%다. 화면에 손목이 분명히 보이는데도 놓쳤다(`figs/px6100890.jpg`). 노트북 카메라처럼 가까운 구도가 우리 목표 환경이라 불리하다.
2. **OpenPose는 안 보이는 관절을 비워 둔다.** 다른 모델은 항상 좌표를 낸다. 카메라가 확대해 팔이 화면 밖으로 나간 7671778에서 OpenPose는 팔을 비웠고, RTMPose·MediaPipe는 팔을 지어냈다.
   그러나 이 경우 지어낸 관절의 점수가 크게 떨어진다. 손목 점수 중앙값이 RTMPose 0.96→0.25, MediaPipe visibility 0.86→0.06, RTMW 6.1→1.3으로 떨어졌다. **점수 기반 관찰 불가 판정으로 대체할 수 있다.** 임계값은 정답이 생긴 뒤 정한다.
3. **RTMW-l이 가장 안정적이다.** 손목·팔꿈치 흔들림이 가장 작고, 손 21점×2를 함께 낸다(가리키기·엄지 들기 라벨에 필요).
4. **MediaPipe IMAGE는 흔들림이 다른 모델의 3~4배다.** VIDEO 모드는 평활로 흔들림을 RTMPose 수준으로 낮추지만, 평활은 지연과 맞바꾼 것이고 합의 거리는 여전히 크다.
5. **팔짱에서는 손목이 가려져 모든 모델의 손목 위치가 서로 다르다**(`figs/px8189172.jpg`, `px8419422.jpg`). 팔짱 판정은 손목보다 팔꿈치·전완 기하에 기대야 한다(라벨 v0 정의와 일치).
6. 좌우 뒤바뀜은 이 영상들에서 거의 없었다(정면 위주라서일 수 있다).

## 결론(잠정)

- **주 추출기: RTMW-l.** 가장 안정적이고 손 좌표를 낸다. CPU 85ms라 실시간에는 GPU 실행 확인이 필요하다.
- **경량 대안: RTMPose-m.** CPU 12ms, 몸 17점만 필요할 때 쓴다.
- **OpenPose: 제안서 기준선으로만 유지.** 가까운 구도의 손목 결측이 커서 주 추출기로 쓰기 어렵다. 또한 CMU 모델은 비상업 라이선스다.
- **MediaPipe: 보조.** 흔들림이 크고 몸 좌표의 손 정보가 거칠다.

## 한계

- 정답 좌표가 없다. "합의 거리"는 다른 모델들의 중앙값과의 거리이지 오차가 아니다. 참조에 RTMPose와 RTMW(같은 MMPose 계열)가 함께 들어가므로 두 모델에 유리할 수 있다.
- 7개 구간, 대부분 1인·정면이다. 다인물·측면·저조도는 다루지 않았다.
- 손 좌표(RTMW 손 42점 vs MediaPipe Hands vs OpenPose hand)는 아직 비교하지 않았다.
